Parcours des tirs

2026·SportJavaScriptShellSQLPython

Ce que fait le projet

Sankey « Shot Flow » des tirs d'un joueur : zone → situation → surface de frappe → résultat, puis passeur, façon de marquer et phase du but. Une fresque, une page interactive et des vidéos par joueur (Mbappé, Kane), publiées sur data-workers.com.

Le projet en action

Comment l'utiliser

pip install -r requirements.txt && npm install
./faire_joueur.sh mbappe

Les commandes se lancent depuis ce dossier.
